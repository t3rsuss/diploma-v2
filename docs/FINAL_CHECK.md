## Межі висновків

- Повне покриття інтервалами не доводить правильності ролей.
- Підтримка правила не є ймовірністю правильності семантики.
- Зберігається відома хибна гіпотеза XDT3 для [15, 17).
- Усі придатні зразки спільного запуску беруть участь
  у відновленні; це не held-out оцінювання.
- CFG1 є синтетичним демонстраційним сценарієм.
- Збіги PE-заголовків, зокрема після XOR-декодування,
  не підтверджують повний коректний виконуваний файл.
- URL і висока ентропія самі по собі не доводять загрозу.
- Потрібен доступний сумісний читач; довільні сторонні
  виконувані програми автоматично не інструментуються.
- Незалежний парсер невідомого формату не генерується.
- Ресурсні обмеження архівів не замінюють ізоляцію процесу.

JOBLIB-моделей у `src/models` та збережено оригінальні байти
двох TXT-моделей. Після отримання виправлення через Git
підтверджено такі SHA-256:
